# ⚔ Knight's Run

A medieval-themed endless runner game — playable in the browser.

**[▶ Play Now](https://ankitky30-tech.github.io/medieval-runner)**

## How to Play

- **Swipe left / right** — change lanes
- **Swipe up** — jump
- **Swipe down** — slide
- On desktop: use **Arrow Keys** or **click** left / center / right

## Features

- 4 obstacle types: barrels, spike traps, trolls, fireballs
- Gold coins to collect
- Speed increases over time
- 3 lives with invincibility frames
- Works on mobile and desktop

## Built With

HTML5 Canvas · Vanilla JavaScript · CSS3
